# ForgeCode Desktop Rebuild

Cross-platform Electron rebuild with a ForgeCode product identity.

## Supported Platforms

| Platform | Architecture | Status |
|----------|--------------|--------|
| macOS    | x64, arm64   | ✅     |
| Windows  | x64          | ✅     |
| Linux    | x64, arm64   | ✅     |

## Build

```bash
# Install dependencies
npm install

# Build for current platform
npm run build

# Build for specific platform
npm run build:mac-x64
npm run build:mac-arm64
npm run build:win-x64
npm run build:linux-x64
npm run build:linux-arm64

# Build all platforms
npm run build:all
```

## Development

```bash
# Windows: install dependencies, sync the upstream Windows bundle, apply all
# local patches, then start the development app.
npm ci
npm run sync -- --force --skip-mac
npm run patch:win
npm run dev
```

## Branding

Brand settings are defined in `branding.json`. The `patch-branding.js` step is
part of `npm run patch`, so a new upstream bundle receives the ForgeCode name,
startup mark, renderer label replacement, isolated development data directory,
and main-process window title automatically.

On Windows, sync also keeps the matching upstream Electron runtime under
`src/win/runtime/`. It is required for the upstream native SQLite module and is
selected automatically by `npm run dev`.

The icon source is `resources/forgecode-mark.svg`. After changing it, regenerate
the package icon files with:

```bash
npm run brand:assets
```

Do not make durable changes directly in `src/`: it is generated by `npm run
sync` and is intentionally ignored by Git.
